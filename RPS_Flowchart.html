Rock Paper Scissors

Command-line game — Logic Flowchart

Start
User runs the script
$ node rockPaperScissors.js rock
Step 1 — Get Input
Slice process.argv
const args = process.argv.slice(2); // process.argv = ['/node', '/script.js', 'rock'] // args = ['rock']
Check — Validation 1
Did the user type anything?
if (args.length === 0) { // nothing was typed }
YES → error
NO → continue
Error → Exit
No input provided
console.error( 'Please provide your move' ); console.error( 'Usage: node rps.js rock' ); return;
Step 2 — Normalise
Get player's move
const playerMove = args[0].toLowerCase(); // 'ROCK' → 'rock'
Check — Validation 2
Is it a valid move?
const validMoves = ['rock', 'paper', 'scissors']; if (!validMoves.includes(playerMove)) { // invalid move }
INVALID → error
VALID → continue
Error → Exit
Invalid move
console.error( `"${playerMove}" is not valid` ); console.error( 'Use: rock, paper, scissors' ); return;
Step 3 — Random
Generate computer move
const randomIndex = Math.floor( Math.random() * validMoves.length ); // Math.random() → 0.0–0.999 // × 3 → 0.0–2.999 // Math.floor() → 0, 1, or 2 const computerMove = validMoves[randomIndex]; // e.g. 'scissors'
Step 4 — Compare
Compare player vs computer
// playerMove = 'rock' // computerMove = 'scissors' if (playerMove === computerMove) → DRAW else if (winning combination) → WIN else → LOSE
Three possible outcomes
Outcome A
🤝 Draw
if (playerMove === computerMove) { result = "It's a draw!"; } // rock vs rock // paper vs paper // scissors vs // scissors
Outcome B
🎉 You Win
if ( (player==='rock' && computer==='scissors') || (player==='scissors' && computer==='paper') || (player==='paper' && computer==='rock') ) { result = 'You win!'; }
Outcome C
😢 You Lose
} else { result = 'You lose!'; } // All other cases // mean the computer // won
