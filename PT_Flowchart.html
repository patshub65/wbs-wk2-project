Rule 1 — Vowel Start
Add "way" to the end

Rule 2 — Consonant Start
Find consonant cluster
let consonantCluster = ''; let index = 0; while (index < word.length && !isVowel(word[index])) { consonantCluster += word[index]; index++; }
While loop — tracing "string"
i=0: 's' → not vowel → cluster='s'
i=1: 't' → not vowel → cluster='st'
i=2: 'r' → not vowel → cluster='str'
i=3: 'i' → IS vowel → STOP ✋
Rule 2 continued — Build Word
Move cluster to end + "ay"
const restOfWord = word.slice(index); // 'string'.slice(3) → 'ing' return restOfWord + consonantCluster + 'ay'; // 'ing' + 'str' + 'ay' → 'ingstray'

Step 6 — Join
